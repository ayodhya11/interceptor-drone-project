01 Project aim

Detect drones in real time from a camera feed, and on the first confirmed detection, connect to Mission Planner to arm and immediately disarm the target drone. Detection runs on a Roboflow-hosted model.

  • Model: Roboflow hosted — {{ model_id }}
  • Inference: Roboflow serverless API, confidence threshold {{ conf_threshold }}
  • Phase 1: webcam + file detection active
  • Phase 2: Mission Planner arm/disarm planned
